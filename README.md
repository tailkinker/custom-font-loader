# Liberation Serif for Foundry VTT

A simple Foundry VTT module that replaces the default sans-serif typeface with **Liberation Serif**.

The module is intended for users who find serif typefaces more comfortable to read, including users with visual impairments or other accessibility needs.

## Features

- Replaces Foundry VTT's default sans-serif typeface with Liberation Serif.
- Includes the Liberation Serif TrueType font files.
- Preserves Foundry's icon fonts and other specialised typefaces.
- Requires no external font downloads or additional dependencies.

## Installation

### Manual Installation

1. Download or clone this repository.
2. Copy the `custom-font-loader` directory into your Foundry VTT `Data/modules/` directory.
3. Start Foundry VTT.
4. Enable **Liberation Serif for Foundry VTT** in the world's Manage Modules settings.

### Module Directory

The module should be installed in:

```text
FoundryData/
└── Data/
    └── modules/
        └── custom-font-loader/
```

## Included Fonts

The module distributes the Liberation Serif TrueType font files (`LiberationSerif-*.ttf`).

The fonts are included locally so that the module does not depend on Liberation Serif being installed on the host operating system.

## Accessibility

Typography is a matter of individual preference and visual comfort. Sans-serif typefaces are not universally easier to read, and some users find serif typefaces substantially more comfortable.

This module provides an alternative for Foundry VTT users who prefer Liberation Serif.
